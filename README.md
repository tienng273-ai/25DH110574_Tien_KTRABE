# MyStore - Website bán hàng

## 1. Thông tin bài

- **Project:** `_25DH110574_Tien_KTRABE`
- **Công nghệ:** ASP.NET MVC 5, Entity Framework 6
- **Database:** SQL Server LocalDB
- **Tên Database:** `MyStore`

## 2. Hướng dẫn chạy

1. Mở Solution bằng Visual Studio.
2. Kiểm tra Database `MyStore`.
3. Nhấn `Ctrl + F5` để chạy website.

## 4. Chức năng chính

### Admin

- Quản lý danh mục
- Quản lý sản phẩm
- Quản lý người dùng
- Quản lý khách hàng
- Quản lý đơn hàng
- Tìm kiếm, lọc và phân trang
- Cập nhật trạng thái đơn hàng
- Quản lý tồn kho

### Customer

- Đăng ký / đăng nhập
- Xem sản phẩm
- Tìm kiếm sản phẩm
- Lọc sản phẩm theo danh mục
- Xem chi tiết sản phẩm
- Thêm sản phẩm vào giỏ hàng
- Cập nhật giỏ hàng
- Đặt hàng
- Xem đơn hàng
- Xem lịch sử giao dịch
- Mua lại sản phẩm
